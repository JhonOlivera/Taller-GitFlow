## Lo que aprendio Juancho 

- Una variable de entorno es un dato con nombre (por ejemplo, una clave o una configuración) que se almacena en el sistema operativo, fuera del código, y que las aplicaciones pueden consultar mientras se ejecutan.

- El archivo .gitignore le indica a Git qué archivos o carpetas debe ignorar, de modo que no se rastreen ni se suban a un repositorio remoto como GitHub. Se usa, por ejemplo, para excluir archivos .env, node_modules o credenciales. 67
## Lo que aprendio Jhon
- Una **variable de entorno** es un dato clave (como una contraseña o una configuración) que se guarda directamente en el sistema operativo en lugar de escribirse en el código. Esto permite que tu aplicación lo consulte en tiempo de ejecución de forma segura y flexible.

- Por su parte, el archivo **`.gitignore`** actúa como un filtro de seguridad y orden para tu proyecto. Le dice a Git exactamente qué archivos o carpetas (como carpetas de dependencias `node_modules`, archivos `.env` o credenciales privadas) debe pasar por alto, evitando que se rastreen o se publiquen por error en plataformas como GitHub.
