## Lo que aprendio Juancho 

- Una variable de entorno es un dato con nombre (por ejemplo, una clave o una configuración) que se almacena en el sistema operativo, fuera del código, y que las aplicaciones pueden consultar mientras se ejecutan.

- El archivo .gitignore le indica a Git qué archivos o carpetas debe ignorar, de modo que no se rastreen ni se suban a un repositorio remoto como GitHub. Se usa, por ejemplo, para excluir archivos .env, node_modules o credenciales. 67
